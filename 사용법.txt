부동산 도우미 0.6.31 · 처음 사용하기

1. RealEstateHelper-Setup-0.6.31-x64.exe를 실행합니다.
2. 바탕화면의 ‘부동산 도우미’를 엽니다.
3. PC 인증 없이 바로 실행됩니다. 인증번호를 발급받거나 입력할 필요가 없습니다.
4. 사용 설정에서 GPT·Gemini·Claude 중 하나를 선택합니다. GPT는 본인 ChatGPT 계정으로 로그인합니다. Gemini는 Google AI Studio, Claude는 Anthropic Console에서 발급한 본인 API 키로 연결합니다. 키는 채팅에 보내지 말고 프로그램에 직접 입력하세요.
5. 단지명, 면적·타입과 궁금한 점을 입력하고 ‘분석 보고서 만들기’를 누릅니다. 같은 이름의 단지가 여러 곳이면 검색 결과에서 선택하세요.
6. 보고서를 확인하고 ‘파일로 저장’을 누릅니다. ‘상세 근거 보기’로 자동 생성된 근거 PDF를 엽니다.

고객 상담 기능
- 새 분석의 ‘고객 조건’을 펼쳐 목적·예산·입주 시기·중요 조건 2개를 선택합니다. 모르는 항목은 비워 둡니다. 월세 예산은 보증금 기준입니다.
- 사용 설정에서 사무소명·담당자·연락처·주소와 선택 로고(PNG/JPEG, 256KB 이하)를 저장합니다.
- 보고서에서 ‘상담 조건·현장 메모’를 펼쳐 매물별 주의사항·고객 전달 메모·확인일을 입력하고 ‘상담 내용 저장’을 누릅니다.
- ‘내부 메모’는 이 PC와 전체 백업에 보관합니다. 고객용 파일·전달문구·AI 분석에는 포함하지 않습니다.
- ‘고객 요약’을 눌러 PDF·PNG 이미지·HTML로 저장하거나 전달문구를 복사합니다. 상세 거래와 근거는 기존 ‘상세 보고서’에서 확인합니다.
- 상담 조건·메모 저장과 요약본 생성은 저장된 자료를 사용하므로 AI를 다시 호출하지 않습니다. 자료 기준일은 바뀌지 않습니다.
- 고객 요약·상세 보고서는 마지막으로 저장에 성공한 폴더를 함께 기억합니다. 재실행해도 유지되며, 취소·저장 실패는 경로를 바꾸지 않습니다. 해당 폴더가 없어지면 문서 폴더에서 시작합니다.
- 이전 보고서의 업소정보는 당시 내용을 유지합니다. 바꾸려면 상담 편집에서 ‘현재 업소정보 적용’ 후 저장합니다.

사용 안내
- 같은 날 같은 아파트·면적·거래 유형으로 다시 만들면 검증된 저장 보고서의 거래·네이버 기본정보·시설·자연환경·추이를 자동으로 재사용해 새 보고서를 만듭니다. 단일·2개·3개 비교에 적용되며 앱을 재실행해도 보관함에서 찾습니다. 고객 조건과 메모는 새 입력을 사용합니다.
- 날짜·단지·면적·유형이 달라지거나 저장 근거·지도·원자료가 불완전하면 자동 재사용하지 않고 정상 조회로 보완합니다. 최신 자료가 필요하면 ‘새 자료로 다시 조회’를 선택하세요.
- ‘네이버에서 확인한 생활정보’ 문단과 별도 보완정보 시트는 출력하지 않습니다. 첫 페이지 세대수·주차대수 등 단지 기본정보는 계속 표시합니다.
- 단순한 주차대수 표시·확인에는 주변 단지 비교를 추가 조회하지 않습니다. 주변 단지와의 주차·연차·지하철 비교나 순위·랭킹을 명시적으로 요청할 때만 선택적 비교 자료를 수집·표시합니다.
- 당일 아파트 보고서에서 ‘새 환경 정보 보완’을 누르면 대형마트·병원·학원 정보를 다시 확인해 새 보완본을 저장합니다. 원본·거래·지도·상담 내용은 보존하며 AI를 다시 호출하지 않습니다. 진행 중에는 ‘중지’할 수 있습니다.
- 평가는 교통·교육·상권·자연·병원·학원의 6개 항목입니다. 상품·가격 경쟁력 점수는 표시하지 않으며, 기존 점수를 새 항목으로 옮기지 않습니다. 실거래 평균과 거래표는 계속 제공합니다.
- 상권은 대형마트·생활 슈퍼·대형 쇼핑시설을 구분합니다. 병원은 종합·대학병원·소아청소년과·정형외과·치과, 학원은 입시·보습·국어·영어·수학의 등록 시설 접근성을 종합합니다. 실제 운영·진료·수업 조건과 안전 동선은 별도로 확인하세요.
- 학원 환경과 과목별 확인정보는 공식 상가정보의 입시·교과학원 분류와 입지톡의 주변 시설·분류·좌표를 사용합니다. 입시·보습, 국어, 영어, 수학 4개 분야의 가까운 시설·직선거리·접근점수를 간단한 표로 표시합니다. 학원 배점은 입시·보습 40%, 국어·영어·수학 각 20%입니다. 같은 날 확인한 시설 응답은 재사용하고 부족한 과목만 보완합니다. 네이버 학원 목록은 표시하지 않습니다.
- 학교별 학업정보·학업성취도·평가 순위는 조회하거나 표시하지 않습니다. 학교명·거리·공식 통학구역·배정 조건 등 기본 교육환경 정보는 유지합니다.
- 당일 아파트 분석에서는 건축HUB 총괄표제부를 먼저 대조하고, 부족한 주차대수·세대수·사용승인일을 네이버 부동산에서 확인합니다. 링크를 미리 입력할 필요가 없습니다. 직접 확인한 링크가 있으면 ‘네이버에서 조회한 단지정보 활용’에서도 가져올 수 있습니다.
- 보고서 첫 페이지 상단에는 확인된 총 주차대수·세대당 주차대수·세대수·출처·조회일이 표시됩니다. 자료가 없으면 ‘미확인’으로 표시합니다.
- 고객용 거래 평균은 7.5억·13.2억처럼 표시합니다. 1억 미만 보증금·월 임대료는 만원으로 표시하며 소수 첫째 자리까지 반올림합니다. Excel 계산표·상세 근거·원거래의 만원 단위 수치와 계산값은 보존합니다.
- 자연환경은 대표 대형공원과 등록 숲길·등산로·수변 산책로를 함께 대조합니다. 확인된 가까운 지점의 직선 접근성을 평가하며, 공식 경로점은 출입구·실제 보행거리와 구분합니다. 서울시 산책로는 공식 경로도 대조하고, 조회된 시설 범위를 표시합니다.
- 배경 지도가 좁게 나오거나 비어 보이면 보고서의 ‘지도 다시 불러오기’를 누르세요. 지도 전체를 확인한 수정본을 새로 보관하며 거래·평가·상담 내용과 원본 보고서는 유지합니다.
- 이번 배포본은 PC 인증을 요구하지 않습니다. 선택한 AI와 지도 서비스 연결은 각각 필요합니다. Gemini와 Claude는 같은 독립 입지톡 연결을 함께 사용합니다.
- 화면과 고객용 보고서에는 AI SHERPA 제작사 마크가 표시됩니다. 상담 부동산의 이름·연락처·로고는 사용 설정에 등록한 업소 정보로 표시됩니다.
- 송도더샵엑스포9단지처럼 통합 명칭으로 등록된 단지는 검색 후 공식 후보를 확인하세요. ‘더샵엑스포9단지 · 송도동 16-6’을 선택하면 해당 단지의 공개 전용면적 목록을 조회합니다.


거래 평균 표의 면적 표시
- 함께 선택한 84.xx㎡ 면적은 84타입으로 간결하게 표시합니다. 서로 다른 정수 면적군을 함께 선택했으면 84~90타입처럼 범위를 표시합니다. 선택 면적·거래·금액의 원자료와 통합 평균 계산은 유지합니다.

보고서 읽는 순서
- 물건·비교 개요 → 환경·가치 평가 → 장단점·선택 기준 → 지도·주변 시설 → 상세 거래·출처 순서입니다.
- 그래프 위 핵심 특징·차이는 저장된 점수와 근거에서 표시하며, 평가 보류나 범위가 다른 점수를 억지로 비교하지 않습니다.


[조회 절약과 입지톡 남은 횟수]
병원·학원·마트 등을 먼저 묶음 조회하고 부족한 종류만 보충합니다. 프로그램 자체 조회 횟수 제한은 없습니다. 네이버에서 확인한 공개 단지정보와 같은 날 저장된 시설 자료를 우선 활용하고, 부족한 항목은 정해진 검색 목록에서 끝까지 보완합니다. 단지 선택 과정에서 이미 사용한 요청도 합산해 표시합니다.
같은 날 같은 단지의 공개 시설 자료는 다른 평형에서도 재사용합니다.
새 자료로 다시 확인하려면 추가 입력의 ‘같은 조건도 새 자료로 다시 조회’를 선택하세요.
분석 버튼 아래에서 입지톡 조회 상태와 보고서별 실제 요청 횟수를 확인할 수 있습니다. 부족한 생활정보는 네이버 공개 검색에서 명칭·분류·전체주소가 확인된 범위만 보완하며, 거리를 확인하지 못한 시설은 거리 점수에 넣지 않습니다.
입지톡이 일일 한도 초과를 알리면 ‘0회 · 오늘 한도 소진’, 잔여 횟수를 제공하지 않으면 ‘확인 불가’로 표시합니다.
‘이번 실행 요청 횟수’는 프로그램 실행 이후의 요청 수이며 캐시 재사용·다른 앱의 조회·내부 지도 API 과금 횟수와 다를 수 있습니다.
Codex와 이 프로그램의 입지톡 연결 인증은 별도입니다. 계정을 바꿀 때는 프로그램의 ‘지도 연결 → 다시 연결’에서도 본인 계정으로 로그인하세요.


[입지톡 원본 스킬 기준 추가]
기존 6개 생활환경 점수의 근거에 역·병원·생활 상권·공원/숲길·초등학교의 거리 신호를 함께 표시합니다.
초품아·배정·통학 안전·도보시간을 거리만으로 확정하지 않습니다.
‘주변 단지 비교’를 누르면 주차·지하철 직선거리·사용승인 만 연차를 추가로 확인합니다.
주변 등록 후보 중 가까운 최대 9곳과 기준 단지의 확인된 표본이며 지역 전체 순위가 아닙니다.
주차 지상·지하 대수 또는 세대수가 없으면 순위를 보류합니다.
‘남은 횟수 보기’는 입지톡 공식 대시보드를 엽니다. 프로그램에 연결한 계정과 브라우저 계정이 같은지 확인해 주세요.

0.6.2: 학교별 공개 학업정보·성취도·평가 순위는 조회·출력에서 제외했습니다. 학교명·거리·통학구역과 기존 6개 생활환경 평가는 유지합니다.

0.6.3: 네이버 부동산 단지·지도 링크에서 공개 단지정보를 가져와 같은 날 공식 단지·주소와 대조한 뒤 재사용합니다. 입지톡 중복 조회를 줄이고, 보고서 첫 페이지 상단에 총 주차대수·세대당 대수·세대수·출처·조회일을 표시합니다.

0.6.4: 네이버 주차정보 자동 조회를 적용했습니다. 입지톡 요청은 보고서당 지도 포함 최대 9회로 제한하고, 묶음 조회의 전체 응답·같은 날 시설 자료·진행 중인 중복 요청을 재사용합니다. 부족한 생활정보는 네이버 공개 자료로 보완합니다.

0.6.5: 프로그램 자체의 9회 제한과 항목별 보완 검색 제한을 제거했습니다. 필요한 정보가 조회 횟수 때문에 생략되지 않도록 보완하며, 학원 자료는 입지톡 신규 조회 없이 공개 웹 검색에서 확인하고, 자료가 확보되면 과목별 세부표를 표시합니다. 네이버 공개 단지정보·주차·생활정보와 같은 날 검증한 캐시를 우선 활용합니다. 외부 서비스의 일일 한도·로그인·오류로 확인하지 못한 정보는 사유를 남깁니다.
