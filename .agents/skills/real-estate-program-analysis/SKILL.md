# AI SHERPA 매물 분석

이 폴더의 `program/`을 분석·출력의 기준으로 삼는다. 0.6.1의 생활환경 6개 항목을 적용하며, 현재 소스의 버전과 실행한 코드 해시를 기록한다. 평균·점수·표를 별도 방식으로 다시 만들지 않는다. **같은 입력·원자료·기준일·비교 범위·엔진이면 프로그램과 같은 결과**여야 한다. 조회 시점이나 자료가 달라진 결과까지 같다고 약속하지 않는다.

이는 재사용할 작업 절차의 저장이며 모델 자체의 학습을 뜻하지 않는다. 현재 사용자 지시와 `AGENTS.md`를 함께 적용한다. 앱이 이미 계산한 자료와 JSON 형식을 제공하며 본문 초안만 요청한 경우에는 그 범위만 수행한다. 분석·프로그램 실행·파일 제작을 중첩하지 않는다.

## 자동 적용과 입력

- “이 매물 분석해줘”, “두 단지 비교 보고서”, “고객용으로 출력”, “프로그램과 동일하게 분석”에 적용한다. 사용자가 스킬을 다시 지명하게 하지 않는다.
- 대상 주소·단지, 자산 유형, 전용면적·타입, 기준일을 확인한다. 동명 단지는 지번·공식 단지번호로 구별한다. 빠진 정보는 분석에 꼭 필요한 것만 묻는다.
- 고객 목적·예산·입주 시기·중요 조건 2개, 업소명·담당자·연락처·선택 로고, 매물별 주의사항·현장 확인일·전달 메모를 제공받은 범위에서 반영한다. 다른 고객의 조건·메모나 가상 예시를 자동 복사하지 않는다. **내부 메모는 고객용 파일에서 제외**한다.
- 거래 유형 미지정이면 매매·전세·월세를 함께 안내하고, 지정했으면 지정 유형만 쓴다. 기준일 미지정은 한국 날짜의 오늘이다. 평균을 제시가격으로 채우지 않으며 상품·가격 경쟁력 점수는 생성하지 않는다.
- 단순 재출력은 저장된 자료를 사용한다. 새 분석·최신 재조회는 실제로 자료를 수집하고 날짜를 기록한다. 과거 기준일에 현재 주차·시설 정보를 소급 적용하지 않는다.

## 같은 엔진으로 분석

새 분석은 [engine-workflow.md](references/engine-workflow.md)의 수집·산정 부분을, 기존 보고서 재출력은 재출력 부분을 읽는다. 필요한 모듈만 확인하고 전체 소스를 반복해서 읽지 않는다.

입지톡 원본 스킬의 추가 적용은 [ipzitalk-integration.md](references/ipzitalk-integration.md)를 따른다. 프로그램의 거리 신호와 선택적인 주변 단지·주차·연차·지하철 비교를 재사용한다. 원본의 독립 보고서들을 중복 실행하지 않는다.

1. 공식 단지·면적 식별 후 국토부 거래를 수집하고 `core.aggregate()`로 집계한다. 동일 단지·선택 전용면적·달력상 최근 6개월의 개별 계약 산술평균이다. 해제·중복·기간 밖 거래를 제외하고 월세 보증금 구간을 분리한다. 평균의 평균을 쓰지 않는다.
2. 입지톡·공식 자료를 수집기에 연결하고 `scoring.assessScores()`로 산정한다. `research.collectResearch()`의 묶음 우선 조회와 `ResearchCache`를 재사용한다. 종류별 조회일·중심·반경·건수 제한을 대조한 뒤 부족한 종류만 추가 조회한다. 같은 날·같은 공식 단지의 공개 시설 자료는 다른 평형·고객 분석에도 재사용하되 고객 조건·메모·거래 평균을 섞지 않는다. 실제 호출 없이 출처·조회일·식별자·검증 완료 상태를 만들지 않는다.
3. 고객용 기본 표는 **교통 환경·교육 환경·상권 환경·자연환경·병원 환경·학원 환경 6개 항목**이다. 부분 점수는 `*`와 평가 범위·한계를 표시한다. 부족하면 `평가 보류`와 사유·필요 자료를 함께 쓴다. 0·1·50점으로 빈칸을 채우지 않는다. 과거 상품·가격 점수를 새 항목으로 옮기지 않는다. 과거 보고서는 `prepareReport()`로 호환 처리하며 새 조회 없는 항목은 보류한다.
4. 단지별 장점·단점과 선택 기준은 저장된 점수·근거에서 생성한다. 범위가 다른 점수의 우열·종합순위를 만들지 않는다. 실거래 평균·표본·기간·거래표는 계속 제공한다.
5. 기존 보고서·요약·지도·차트 출력 모듈을 사용한다. 계산값과 전체 근거는 내부 JSON·검증 자료에 보존한다.

## 꼭 유지할 보완 기준

- **자연환경:** 지역 대표 대형공원의 공식 규모와 함께 숲길·등산로·수변 산책로를 대조한다. 검증된 가까운 지점의 직선 접근성을 같은 거리 구간으로 부분 평가한다. 산 정상·대표 핀·공식 경로 최근접점과 실제 출입구·도보거리를 구분한다. 개방·통제·경사·계단·조망은 확인한 내용만 쓴다. 특정 단지 점수를 예외로 고정하지 않는다.
- **상권:** 대형마트를 명시적으로 조회하고 대형 쇼핑시설·생활 슈퍼와 구분한다. 이름만으로 대형마트를 판정하지 않는다. 병원 접근성은 별도 병원 환경에서 평가한다.
- **병원·학원:** `living-access.cjs`의 종류별 조회·반경·고정 배점·거리 구간을 재사용한다. 병원은 종합·대학병원, 소아청소년과·정형외과·치과, 학원은 입시·보습·국어·영어·수학만 종합한다. 학원 배점은 입시·보습 40%, 국어·영어·수학 각 20%이다. 검색 오류·자료 제한·정상 빈 결과를 구분하고, 시설 수를 중복 가산하거나 검색어만으로 진료과·교습과목을 확정하지 않는다. 등록 직선 접근성 점수는 의료 수준·응급진료·입시 성과를 뜻하지 않는다.
- **학교 정보:** 학교별 공개 학업정보·학업성취도·평가 순위와 관련 표·링크는 조회·출력에서 제외한다. 학교명·거리·공식 통학구역·배정 조건과 확인된 통학 동선은 유지한다.
- **금액·면적:** 고객용 평균은 프로그램처럼 `7.5억`, `13.2억`으로 표시한다. 작은 보증금·월세는 만원, 원자료·Excel 계산표·상세 검증값은 원래 만원 단위와 정밀도를 보존한다. 여러 84.xx㎡는 84타입, 서로 다른 정수 면적군은 범위를 표시한다. 2평 이상 차이나는 선택 면적은 프로그램의 보고서 분리 기준을 따른다.
- **지도:** 입지톡이 실제 렌더링한 이미지를 본문에 포함한다. 대상·핵심 시설·범례·제공자·조회일·직선거리 기준을 표시한다. 좁은 띠·빈 타일·잘림이 있으면 완료 처리하지 않는다. 링크만으로 대신하거나 AI로 증거 지도를 만들지 않는다.

## 고객용 출력과 완료

- 순서: **물건·6개월 평균 → 환경·가치와 핵심 차이 → 장단점·선택 기준 → 지도·시설 → 상세 거래·출처**. 첫 화면에서 핵심을 읽게 하고 내부 처리 과정은 본문에서 뺀다.
- `program/src/brand-theme.*`와 기존 로고·스타일을 재사용한다. AI SHERPA 제작사 표시와 상담 업소 정보를 구분한다. 별도 디자인을 새로 만들지 않는다.
- 형식 미지정 시 PDF를 기본으로 하고 HTML·JSON 원본을 보관한다. 고객 요약 요청이면 요약을 우선하고 Word·PPT·Excel을 불필요하게 모두 만들지 않는다.
- `AGENTS.md`의 로컬 형식별 스킬을 적용한다. 최종 PDF는 전 페이지를 렌더링한다. 마지막 본문이 7줄 이하로 남는 꼬리 페이지는 내용 삭제·과도한 글자 축소 없이 재배치하고 다시 확인한다.
- `reports/YYYY-MM-DD_대상명/`에 원자료·그림·근거·최종 파일을 구분한다. 보완본은 원본·상담·다른 평가를 보존하고 변경 범위를 기록한다. 재출력·메모 변경에는 AI 분석을 다시 호출하지 않는다.
- 평균·표본·기간·단지 식별, 6개 점수의 범위·사유, 지도 이미지, 메모 공개 범위와 페이지를 확인한다. 엔진·자료·지도·렌더러가 없으면 프로그램과 동일하게 검증 완료했다고 하지 말고 미확인 범위를 알린다.
