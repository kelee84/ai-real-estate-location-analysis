# 마지막 PPT 기본 템플릿

새 PowerPoint를 만들거나 기존 PPT를 수정할 때, 사용자가 다른 템플릿을 명시하지 않았으면 `assets/TTTM_분석프로그램_설계서_기본템플릿.pptx`를 기준으로 작업한다.

## 기본 서식

- 16:9 화면비와 원본 슬라이드 크기를 유지한다.
- CRESSEM 로고, 표지 이미지, 표지의 주황색 제목 계열, 상단 주황색 구분선, 연한 파란색 배너를 유지한다.
- 제목은 검은색 굵은 글씨와 `■ 번호. 제목` 형식을 우선 사용한다.
- 본문은 한글 가독성을 위해 맑은 고딕 계열을 사용하고, 글자 간격·줄바꿈·여백을 원본처럼 유지한다.
- 표는 연한 파란색 헤더, 얇은 밝은 테두리, 흰색/아주 옅은 회색 교차 행을 사용한다.
- 컴포넌트 다이어그램은 평면 사각형, 제한된 색상, 명확한 방향 화살표를 사용한다.
- 시퀀스 다이어그램은 빨간색 호출선, 파란색 점선 반환선, 세로 생명선과 읽기 쉬운 메시지 배치를 사용한다.
- 표와 다이어그램은 가능한 한 PowerPoint에서 수정 가능한 native 객체로 만든다. 이미지로 합치지 않는다.

## 작성 및 검토 규칙

- 템플릿의 공통 마스터, 로고, 표지 이미지, 페이지 번호 영역을 우선 재사용한다.
- 새 내용은 템플릿의 제목·배너·본문 글자 크기와 간격에 맞춰 배치한다. 텍스트를 억지로 축소하지 말고, 먼저 문장을 줄이거나 줄바꿈을 조정한다.
- 사용자가 별도 디자인, 회사 양식, 첨부 PPT를 제공하면 그 지시를 이 스킬보다 우선한다.
- 생성 후 모든 슬라이드를 PowerPoint에서 렌더링해 글자 잘림, 겹침, 표 테두리, 화살표 방향, 페이지 번호를 확인한다.
- 원본 템플릿 파일은 수정하지 않고, 항상 새 파일로 결과를 저장한다.

## 적용 범위

이 스킬은 PPT/PPTX 작성·수정 요청에 자동 적용한다. 단순한 PPT 내용 설명이나 사용자가 명시적으로 다른 템플릿을 지정한 경우에는 해당 요청을 우선한다.
